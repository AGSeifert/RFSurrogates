# Mutual Impurity Reduction (MIR)

Mutual Impurity Reduction (MIR)

## Usage

``` r
MutualImpurityReduction(REL)
```

## Arguments

- REL:

  A \[MeanAdjustedAgreement()\] or \[MutualForestImpact()\] object.

## Value

A \`MutualImpurityReduction\` list object. \* \`REL\`: The
\[MeanAdjustedAgreement()\] or \[MutualForestImpact()\] object. \*
\`MIR\`: Mutual Impurity Reduction \* \`AIR\`: Actual Impurity Reduction
