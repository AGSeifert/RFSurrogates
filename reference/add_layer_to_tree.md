# Internal function

This function adds the respective layer to the different nodes in a
tree. The tree has to be prepared by getTree function.

## Usage

``` r
add_layer_to_tree(tree)
```

## Arguments

- tree:

  A tree data frame from
  [`getTreeranger()`](https://agseifert.github.io/RFSurrogates/reference/getTreeranger.md).

## Value

A tree data frame with `layer` added.
